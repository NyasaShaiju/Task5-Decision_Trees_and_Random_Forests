# Task5-Decision_Trees_and_Random_Forests
This project demonstrates the application of Decision Tree and Random Forest classifiers using the heart.csv dataset to predict heart disease. 
The workflow includes:
1.Training and visualizing a Decision Tree Classifier.
2.Analyzing overfitting and controlling model complexity using max depth.
3.Training a Random Forest and comparing model performance.
4.Interpreting feature importances.
5.Evaluating both models using 5-fold cross-validation.

Tools Used: Python, Scikit-learn, Matplotlib, Pandas
